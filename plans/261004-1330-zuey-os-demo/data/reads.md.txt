## [MCP vs CLI: Benchmarking Tools for Coding Agents](https://mariozechner.at/posts/2025-08-15-mcp-vs-cli/)
- Source: mariozechner.at · web
- URL: https://mariozechner.at/posts/2025-08-15-mcp-vs-cli/

The author compared the performance of using a Model Context Protocol (MCP) versus a Command Line Interface (CLI) for coding agents. They found that using CLI tools directly often outperforms MCPs, which can flood the context window with unnecessary output and degrade agent performance. However, MCPs can be useful for stateful tools and when there are no easy-to-use CLI tools available. The author created a custom MCP server and CLI tool to evaluate the difference, finding that the CLI tool was faster and more efficient in some cases.
